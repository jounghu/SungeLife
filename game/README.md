# 什么都没有发生

根据虚构短篇改编的极简叙事游戏原型（游戏内人物已全部化名：苏夏、苏国庆、夏心爱）。单文件、零依赖、零外部资源，双击 `index.html` 即可游玩。

## 运行方式

- 直接双击 `index.html`
- 或者起一个本地服务器（防止以后引入外部素材时出现文件协议限制）：
  - `python -m http.server 8000`，然后访问 `http://localhost:8000`
- 建议点右上角"全屏"游玩；浏览器里打开声音，声音全是现场合成的，不需要任何音频文件

## 操作方式

- **点击 / 回车**：推进文字。打字中点一下 = 当前行立即打完；再点一下 = 翻到下一行；全部读完后再点一下 = 出现选项 / 进入下一场景
- **数字键 1–9**：直接选择对应选项
- 磨指甲小游戏：鼠标按住从左往右拖（空格键可代替）；贴胶带小游戏：点击六处漏光点

## 图片资源：全部代码生成

这个游戏刻意走"黑底白字、少数几个意象"的路线，所以**没有任何图片文件**，所有视觉都由代码现场绘制：

| 视觉 | 实现方式 | 位置 |
|---|---|---|
| 2007 年那张像素照片 | Canvas 程序化生成，分辨率随剧情逐幕降低（28→5），越到后面越糊 | `drawPhotoOn()` |
| 卡特兰的香蕉 | 内联 SVG（香蕉 + 胶带） | `showMeet2()` |
| 太平洋 | 动态 Canvas（渐变 + 波浪线） | `startSea()` |
| 磨指甲 | CSS + 指针交互（进度点、抖动反馈） | `nailMini()` |
| 贴胶带的窗户 | CSS 窗口 + 六个可点击漏光点 | `tapeMini()` |
| 电话 | 内联 SVG + 等宽计时器 | `startCountdown()` |
| Claude Code 终端 | CSS 终端 + 真实输入框，逐字输出 | `showTerminal()` |
| 电影颗粒 / 暗角 | CSS 噪点纹理（内联 SVG feTurbulence）+ 径向渐变 | `#grain` / `#vignette` |
| 地点时间字幕卡 | 场景切换时淡入淡出的地点卡 | `showStamp()` |

这样做的好处：无版权风险、文件只有几十 KB、改动即所见。将来如果想让画面更"实"，可以：

1. 新建 `assets/img/` 目录，放入想用的图片；
2. 在场景函数里把 `putPhoto(...)` / `startSea()` 的 innerHTML 换成 `<img src="assets/img/xxx.png">`；
3. 素材优先找 CC0 / 公有领域来源，例如 Unsplash、Pixabay、Openverse。

## 声音资源：全部现场合成

声音用 Web Audio API 实时合成，同样零文件：

| 声音 | 合成方式 | 触发 |
|---|---|---|
| 低音氛围（drone） | 55Hz + 82.41Hz 正弦波，轻微失谐 | 主菜单、室内场景 |
| 海浪 | 布朗噪声 + 低通滤波 + 慢速 LFO | 特纳里费 / 马尔代夫 / 洛杉矶 |
| 心跳 | 低频正弦脉冲（双跳模式） | 结局场景 |
| 电话铃声 | 440Hz + 480Hz 双音 | 第八天那通电话 |
| 磨指甲 | 高频带通噪声刮擦 | 磨指甲小游戏 |
| 胶带 | 高通噪声短促爆音 | 贴胶带小游戏 |
| 时间滴答 | 每秒一个短三角波 | 十一秒静默计时 |

如果将来想要真实录音质感，推荐以下 CC0 / 免版权音源，下载后放 `assets/audio/` 并替换 `AudioSys` 里对应函数：

- 海浪 / 环境声：[freesound.org](https://freesound.org)（筛选 CC0）、[Pixabay Sounds](https://pixabay.com/sound-effects/)
- 电话音：Freesound 搜 "phone ring DTMF"
- 钢琴 / 低音垫：可以用 [Spitfire LABS](https://labs.spitfireaudio.com) 的免费采样自己录几轨

## 游戏结构

```
开篇 · 蒙太奇      三拍：电话对峙（卵子与五千万）→ 空置的楼层（清洁工、凡尔赛宫、湾流）→ 第八天电话
引子 · 2007–2019   "十九年前"闪回：存图（不存 → 结局四）、校内网、羽绒服、《战国》《长城》、苏夏宇宙、十九年导图
第一幕 · 瑰丽酒店  见面、香蕉、包场电影 → 磨指甲小游戏 → 四十几页调查报告（可翻阅）
第二幕 · 特纳里费  三十人 A330、"叫我妈妈"、黑胶带工艺、泰德公园日落、许愿
第二幕 · 马尔代夫  换小飞机、DY、威胁者八万、索尼娃贾尼（贴胶带小游戏）、
                  前任与纹身、彩礼三千万、删照片又找回、撕番位、求婚、露台算日子、第十四天
第三幕 · 香港      见父母、五张卡、海南过年、烟花一百万人、情人节、抽血八管、看房
第三幕 · 洛杉矶    第八天电话（先亲手接起）
  ├─ "让我想想" → Claude Code 终端（亲手敲指令）→ 第二天电话 → 十一秒静默
  └─ "好，我转" / "不" → 直接进入对应结局
尾声              心跳、维港、结账清单、照片、指甲、预产期提醒、一百万人
```

四个结局：

| 结局 | 触发条件 | 一句话 |
|---|---|---|
| 一·什么都没有发生 | 说"让我想想"，然后在十一秒里保持沉默 | 沉默没有留住她 |
| 二·她回来了 | 第八天直接说"好，我转" | 你始终不知道那算不算爱 |
| 三·第一次说不 | 剧情中任何一次说"不" | 你终于哭出来了 |
| 四·从未开始 | 引子选择"关掉窗口" | 什么都没有存，什么都不会发生 |

隐藏数值：钱 / 沉默 / 相信 / 说不。底部 HUD 会实时显示，结局结算时会揭晓它们意味着什么。

## 想改内容？看这里

- 文本：全部在 `index.html` 的 `showXxx()` 场景函数里，`say([...])` 数组就是台词。
- 分支与数值：每个选项 `{t: '按钮文字', fx: {money:1, trust:1, ...}, goto: '下一场景'}`。
- 结局判定：`go()` 场景路由 + 四个 `showE1..E4()`，条件写在各结局的触发选项里。
- 小游戏难度：磨指甲改 `dx > 42` 的判定阈值；胶带改 `tapeLeft` 初始值。
- Claude Code 终端的四步指令：在 `runTermCommand()` 的 `step === 0..3` 分支里改提示词和 Claude 的回复。
- 调查报告的四页内容：在 `renderReportPage()` 的 `pages` 数组里改。
- 马尔代夫 / 香港各小段的台词：`showM1()..showM15()`、`showHK1()..showHK6()`。
- 沉浸层：字幕卡文案在 `STAMPS` 表里；颗粒浓淡改 `#grain` 的 `opacity`；暗角强度改 `#vignette` 的渐变。
- 全屏适配：全屏时正文会自动缩小字号（13–17px）尽量一屏放下；实在放不下时，只在舞台内部滚动，不拖整个页面。
